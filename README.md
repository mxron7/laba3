# Эн • Сад удачи

Учебное веб-приложение с ежедневными омикудзи, профилем и каталогом талисманов. Интерфейс — HTML, CSS и JavaScript, хранение и авторизация — Supabase.

## Запуск
Из корня выполните `python -m http.server 8000 --directory public` и откройте http://localhost:8000. Гостевой режим работает без настройки.

## Подключить Supabase
1. Создайте пустой проект Supabase и включите вход по email и паролю.
2. Выполните в SQL Editor файлы из `supabase/migrations` по очереди: 001, 002, 003. Сделайте это до первой регистрации.
3. В `public/config.js` укажите URL проекта и публичный publishable или anon key. Ключ service_role и секретные ключи принадлежат только серверу.
4. В Authentication → URL Configuration задайте Site URL для локального запуска или опубликованного сайта. Если требуется подтверждение почты, перейдите по ссылке из письма.
5. Зарегистрируйтесь, вытяните листок и проверьте профиль. При повторном запросе в тот же день сервер вернёт тот же листок. Новый день начинается в полночь во Владивостоке. Баланс хранится в public.users.

## Публикация
Для нового приватного репозитория запустите в корне проекта после входа в GitHub CLI:
```sh
gh repo create omikuji-garden --private --source=. --remote=origin --push
```
Команда сохраняет всю историю. Для проверки выполните `git log --oneline --reverse`. Чтобы преподаватель увидел приватный проект, добавьте его аккаунт в Collaborators.

Для размещения на Vercel импортируйте репозиторий. Каталог выдачи public задан в vercel.json. После публикации обновите Site URL в Supabase.

## Границы этапа
Готовы главная, гостевой листок, регистрация и вход, профиль с двумя балансами, ежедневный серверный розыгрыш и каталог. Гостевой листок не меняет баланс. База включает таблицы под подарки, желания, поддержки, талисманы и тестовые пополнения.

Следующий этап — переводы и стена желаний, затем рейтинг по gifts и wish_supports, демо-пакеты 100/500/1000 монет, покупка и экипировка. Три слота ограничены базой. Эффекты на карточках описывают будущую механику. До изменения заполненной схемы сохраните резервную копию.
