# Эн • Сад удачи

Учебное веб-приложение с ежедневными омикудзи, профилем и каталогом талисманов. Интерфейс — HTML, CSS и JavaScript, хранение и авторизация — Supabase.

## Запуск
Из корня выполните `python -m http.server 8000 --directory public` и откройте http://localhost:8000. Гостевой режим работает без настройки.
