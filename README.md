# Сад Удачи.

Учебное веб-приложение с ежедневными омикудзи, рейтингом и каталогом талисманов. Интерфейс — HTML, CSS и JavaScript, хранение и авторизация — Supabase.

## Про сайт

Сам сайт находится по ссылке https://удачитель.site.

Идея сайта - это получать и дарить удачу пользователям сайта. например, если хотите пожелать удачи студентам на сдачу экзаменов, вы можете отправить им конверт с пожеланиями + если будете дарить удачу каждый день, вы сможете попасть в раздел рейтинга Дарителей, а люди с наибольшим количеством удачи будут попадать в также отдельный рейтинг Удачных людей.

Раз начали говорить про техническую составляющую сайта, продолжим эту тему. Кроме рейтинга, вы можете достать Омикудзи - традиционное японское гадание и сам бумажный листочек с предсказанием. Чтобы его достать перейдите на Главную и нажмите кнопку "Вытянуть листок", на экране представится выбор из 3 листочков - какой достанете, такова ваша удача на день. Вытягивание листа работает по 1 разу в день, отсчёт дня начинается в 00:00 по Владивостоку.

Кроме этого Вы можете перейти в раздел "Талисманы" и приобрести их за, пока что, демо-донат. У каждого Талисмана есть свои баффы, подробно можете прочитать в карточках. Чтобы их активировать, необходимо перейти в "Профиль", пролистать вниз и подставить в указанные окошки(максимум можете поставить только 3 Талисмана, можно повторять). Вы также можете отправить их другим пользователям.

А в разделе профиль, будет показано Ваше имя, удача, баланс и как раз таки закреплённые Талисманы. Ваш профиль могут просматривать остальные пользователи.
