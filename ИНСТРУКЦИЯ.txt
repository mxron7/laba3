Обновление для mxron7/laba3, основа — коммит 70d6597.
1. В папке репозитория обнови main командой git pull. Если у тебя есть свои правки в тех же файлах, сначала сравни версии.
2. Скопируй папки public и supabase из архива в корень проекта с объединением папок и заменой одноимённых файлов.
3. В существующем проекте Supabase открой SQL Editor, вставь содержимое supabase/migrations/005_envelopes.sql и нажми Run один раз. Для новой базы сначала выполни миграции 001–004.
4. Из корня проекта запусти py -m http.server 8001 --bind 127.0.0.1 --directory public и открой http://localhost:8001.
5. После входа открой Профиль → Красные конверты. Найди второго пользователя по имени, выбери его и отправь положительное количество удачи. Удачу можно получить за ежедневный листок. Получатель видит конверт при открытии входящих, сумма зачисляется сразу.
6. В Профиль → Пополнить монеты выбери тестовый пакет. Данные карты вводить не нужно.
7. На главной выбери один из трёх листков. Повторное открытие показывает твой ежедневный результат. Для повторной анимации нажми «Вытянуть пробный листок».
